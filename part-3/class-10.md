## Learning goals

1. Understand ways in which new technologies amplify biosecurity risks.
2. Place these new risks in the context of the history of biological weaponization/terrorism.
3. Distinguish different kinds of harm: hallucinations; enhancing evildoers; accident + BW.
4. Become aware of extreme bio-attack scenarios considered salient by some experts.

## Before class

### Read

1. **[A.I. Bots Told Scientists How to Make Biological Weapons](https://www.nytimes.com/2026/04/29/us/ai-chatbots-biological-weapons.html)**. G.J.X. Dance. *New York Times*, April 29, 2026. (2 pages)

2. **[Anthropic Claude Threat Intelligence Report, September 2026](https://www.anthropic.com/threat-intelligence-report-september-2026#biological-misuse-sep-26)**. (8 pages)

3. Four corners: "We should do all we can to stop bad actors even if that slows progress. We can make meaningful dents in the risks if we are willing to slow progress."
