## Before class

### Read

1. **[Why ex post peer review encourages high-risk research while ex ante review discourages it](https://www.pnas.org/doi/10.1073/pnas.2111615118)**. K. Gross, C.T. Bergstrom. *PNAS* 2021;118(51):e2111615118.
   - Read or read part and get an AI summary. This paper is really well written: read from the start through the end of the "Theory" section, and also the Discussion. The rest is quite mathematical but makes an important conceptual point about how the system doesn't work as well as Polanyi would imagine. The math is not the point, so this is a great time to ask AI how this relates to funding science, but read the real text at the start and end.
